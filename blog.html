Internet

Internet is a global network of computers that are connected and can share information. The internet is broken into three simple parts

  1. Device, example: laptop,phone and a tablet.
  2. Servers: Servers are powerful computers that stores websites.
  3. Network: It is what helps to connect examples: mobile data, wifi,

Web Browser

Web Browser is the application that is use to access the internet
Example: Google,Opera Mini,Firefox,Microsoft Edge.

Code Editor

A code editor is a software (application) That developers use to write and edit code when building websites or apps.
Example: Visual studio code(VS Code), sublime text, notepad++ etc.
